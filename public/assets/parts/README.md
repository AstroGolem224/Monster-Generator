# Monsterteile-Assets

Hier liegen die Bilddateien pro Kategorie. Ohne Dateien werden im Generator farbige Platzhalter angezeigt.

## Struktur

- Pro Kategorie ein Ordner: `body`, `head`, `eyes`, `mouth`, `horns`, `arms`, `legs`, `accessories`
- Pro Teil eine Datei: `0.png`, `1.png`, `2.png`, … (PNG mit Transparenz oder SVG)
- Namenskonvention: `<categoryId>/<partId>.png` (z. B. `body/0.png`, `eyes/2.png`)

## Empfehlung

- Einheitliche Größe/Registration pro Kategorie (z. B. 256×256 px, Monster-Mitte = Bildmitte)
- Süß, rund, „dick“ – pastellig, keine harten Kanten
